# WEREWOLF_NARRATOR TOOL #
一个单文件网页应用,帮助线下狼人杀主持人(上帝)轻松带一整局游戏。支持预设板子、自定义配置或线下抽卡"边观察边记录"三种分配身份方式,涵盖20多种角色(含进阶扩展角色)。游戏中按标准顺序逐步引导夜晚流程,自动处理守卫救人、女巫用药、猎人开枪、情侣殉情、双刀等复杂联动,自动记录死因与逐夜日志,并处理警长竞选与投票放逐。纯离线运行,无需联网,适合实体面杀使用。
